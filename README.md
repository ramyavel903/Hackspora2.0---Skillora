## Problem Statement
ScamCheck - Opportunity Verification is a hackathon project focused on helping users identify potential online scams.

##  Project
We are building a simple and user-friendly scam detection application.
The application allows users to enter opportunity details such as:

* Company name
* Opportunity type
* Contact email
* Website / URL
* Opportunity description
* Payment requirement

ScamCheck analyzes the submitted information and provides:

* Risk score
* Risk level: LOW / MEDIUM / HIGH
* Warning indicators
* Simple explanation of the result

##  Tech Stack

## How It Works
Enter Opportunity Details → Analyze → Get Risk Result
The system checks the opportunity for suspicious indicators and shows the user the detected warnings and risk level.
